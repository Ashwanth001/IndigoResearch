# Figure Index — evaluation results

All figures are evaluation-results charts (bar per metric, radar/pentagon, heatmap) — the kind you display to show how each method performed. 150 dpi PNG, white background. Regenerate any time (they read the live CSVs):

```powershell
python3.14 presentation/build_presentation_figures.py
```

Two regimes are covered:
- **sampled** — the sampled test set (~14.5% positive); use for *fair method ranking*.
- **universe** — the full unsampled universe (~1.7% positive); use for *deployment-realistic absolute numbers*.

## Which to put on which slide (suggested)
- **Headline / overall winner:** `metric_sampled_prauc.png`
- **Where GNNs earn their keep:** `metric_sampled_cwr.png`
